DongPS - Photoshop AI 改图工作台  使用说明
========================================
作者：AAdong    反馈 / 联系：QQ 2584818650
适用版本：v1.9.38 及以后

【一、这是什么】
  在 Photoshop 面板里直连生图大模型 API，把生成结果直接应用到当前文档。
  - 文生图 / 指令改图 / 风格化 / 选区局部重绘（结果原位贴回，选区外像素不动）
  - 参考图来源：当前文档、当前图层、当前选区，另可追加最多 9 张参考图（多图融合）
  - 透明底：提示词里写「透明底 / 透明背景 / 抠图」等，出图自动转为真透明 PNG（背景纯白时效果最好）
  - 导出：把文档里的图层组批量导出为图片（PNG / JPG，整幅画布或按组内容裁剪）
  - 不内置任何厂商预设：任意 OpenAI 兼容生图平台、阿里云百炼 DashScope 协议均可直连，插件按端点自动适配

【二、安装】
  1. 完整解压本压缩包到任意目录；保存文档后完全退出 Photoshop
  2. 双击「Install.bat」
     自动完成：备份旧版 → 复制插件到 %APPDATA%\Adobe\CEP\extensions\com.lx.psai.workbench
     → 逐文件校验 → 开启 CSXS.9 ~ CSXS.13 的 PlayerDebugMode（未签名扩展必需）
  3. 重新打开 Photoshop，菜单：窗口 → 扩展（旧版）→ DongPS
  环境要求：Photoshop 2021 及以上（CEP），已在 Photoshop 2026 实测

【三、配置 API】（面板底部「API 设置」，默认折叠，点标题展开）
  1. 端点：填完整 URL（一般到 /images/generations）。
     例：火山方舟  https://ark.cn-beijing.volces.com/api/v3/images/generations
         硅基流动  https://api.siliconflow.cn/v1/images/generations
         阿里云百炼 https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation
                     （该原生端点无模型列表接口，属正常）
  2. API Key：各平台控制台获取（仅保存在本机配置文件）
  3. 模型 ID：可直接填，也可点「自动识别模型」拉取列表后从下拉里选；
     阿里云 DashScope 原生端点请直接手填模型名（如 qwen-image-3.0-pro）
  4. 「端点体检」：只探测连通性，不生成图片、不产生费用
  5. 「保存设置」：以下情况会自动保存，无需手动点——填入/修改端点、Key、模型后离开输入框即落盘
  配置保存在：%APPDATA%\DongPS\dongps_config.json（重启 Photoshop 不丢）

【四、我的预设】（保存整套 API 配置，一键切换）
  - 存为预设：填好 端点/Key/模型 → 在名称框写个名字（留空按“主机·模型”自动命名）→ 点「存为预设」
  - 切换：在「我的预设」下拉里选一个 → 端点/Key/模型立即填入
  - 更新：选中某个预设 → 改动后点「存为预设」即覆盖更新（名称框留空时作用在选中的预设上）
  - 删除：下拉选中 → 点「删除」
  - 最多保存 20 个，新存的排在最前

【五、使用流程】
  1. 在 PS 打开图片或新建文档
  2. 选参考图模式：
       当前文档 = 整图改（换背景、调风格、扩图）
       当前图层 = 只取某一图层内容
       当前选区 = 局部重绘（先用选框/套索框住要改的区域）
  3. 选「风格模板」或自己写提示词
       局部重绘建议：只描述要改的部分，例如「把标价 550 改成 300，字体颜色位置不变」
  4. 输出参数：
       尺寸：自动（按画布）/ 1K / 2K / 3K / 4K / 自定义宽高
             注：部分模型有硬性档位（如 Seedream 4.0+ 无 1K 档），插件会自动改按 2K 并在状态栏说明
       出图张数：1~4 张（并行生成，总耗时≈单张，按张计费）
             提示词里写了「N 张」时以提示词为准（上限 4 张）
             多张时：第 1 张按当前模式置入，其余作为图层放进文档（默认隐藏，图层面板点亮眼睛即可对比）
       边缘羽化：仅用于消除接缝锯齿，建议 1~3px
  5. 点「生成并置入当前文档」
  6. 结果以智能对象成为新图层；「结果预览」可查看，「本次历史」点缩略图可重新置入
  7. 状态栏会显示耗时明细：准备(参考图/尺寸) ｜ 模型 ｜ 置入 ｜ 合计，便于判断慢在哪一步
     （模型耗时占绝对大头时，把尺寸调小一档通常能显著提速）
  8. 透明底：提示词里点明「透明底」或「抠图」（如「白色运动鞋，透明底」）——
     插件会自动把透明诉求改写为纯白背景请求，出图后自动抠白为真透明 PNG
     （若该端点本身支持透明输出，检测到已是透明图则跳过抠白；局部重绘模式不适用）

【七、导出组为图片】（面板「导出组为图片」，默认折叠）
  用途：把文档里做好的图层组批量导出成图片（电商多 SKU / 多规格图常用）。
        一个组里放了多张图时，可选择「组内每项一张」把每张图分别导出
  1. 在 PS 图层面板把要导出的内容编成组（多选图层后 Ctrl+G）
  2. 面板展开「导出组为图片」→ 点「读取文档中的组」→ 列出所有顶层组（默认全部勾选）
  3. 勾选要导出的组，可用「全选 / 全不选」快速调整
  4. 粒度（决定导出几张、文件名怎么取）：
       整组一张     = 一个组导出 1 张，组内所有图层合成后导出，文件名 = 组名（默认）
       组内每项一张 = 组内每个图层/子组各导出 1 张，文件名 = 图层名
                      （组里放的是多张成品图时选这个，一次全部导出）
  5. 格式：PNG（保留透明）/ JPG（可设质量 1~100，建议 85~95）
  6. 范围：
       整幅画布     = 各图尺寸一致，保留原始构图位置（默认）
       按组内容裁剪 = 去掉四周空白；逐张导出时按该图层内容裁剪，各图尺寸可能不同
  7. 导出目录：三种方式任选——① 点「选择目录…」；② 点「用文档目录」（取当前文档所在文件夹）；
     ③ 直接把路径粘贴到输入框。目录会被记住；留空时自动导出到系统「图片」目录，不会卡住导出
  8. 点「导出选中的组」，状态栏逐张显示进度、尺寸与文件大小，结束后汇总成功/失败数
  说明：
  - 导出在文档副本上完成：不会改动原文档，也不会改变任何图层的可见性
  - 原文档中隐藏的组也能导出（导出时自动临时显示该组）
  - 组内所有图层都被隐藏的组会被跳过并提示
  - 同名组自动加序号（如「组名_2.png」）；输出目录里同名文件会被覆盖
  - 只列顶层图层组；嵌套子组请先拖到顶层，或用「当前图层」参考图模式另行导出
  - 「组内每项一张」导出的是组内的直接子项（图层或子组）；子项内部若还有嵌套结构，会作为整体导出

【六、常见报错与处理】
  401 / 403        Key 无效或无权限：核对 Key 是否复制完整、是否属于该端点对应平台与业务空间
  400 / 422        参数或尺寸不被该模型接受：换 2K/3K 档或检查模型名是否正确
  402              余额 / 额度不足
  404              端点路径不存在：确认是否包含 /images/generations（或该平台提供的正确路径）
  识别失败: Failed to fetch
                   请求没到达服务器：检查端点地址、本机网络/代理；该平台若不开放模型列表接口属正常，
                   直接手动填写模型 ID 即可
  LLM Provider NOT provided
                   网关要求模型名带 provider 前缀（第三方中转站常见）：把模型名写成 openai/<模型名>
  无可用渠道（distributor）
                   中转站未给该模型配置渠道：换模型或换平台，与插件无关
  面板不显示        ① 是否已完全退出并重启 PS ② PlayerDebugMode 是否为 1
                   ③ 插件是否完整位于 %APPDATA%\Adobe\CEP\extensions\com.lx.psai.workbench
  改了设置不生效    面板代码常驻内存，更新插件或改配置后需重载：彻底退出 PS 再打开

【八、关于数据与费用】
  - API 调用按所选平台计费规则执行，图像会上传到你配置的图像服务商
  - 插件不收集、不上传任何数据；API Key 与预设仅保存在本机配置文件
  - 「软件声明」与赞助收款码为面板内置内容，赞助完全自愿，不影响任何功能

【九、卸载】
  删除文件夹：%APPDATA%\Adobe\CEP\extensions\com.lx.psai.workbench
  （如需一并清配置：删除 %APPDATA%\DongPS\dongps_config.json）
